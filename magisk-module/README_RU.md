# TgBypass All-In-One (Vector + Service)
### Автор: windyx0
### Модуль для Magisk / KernelSU / APatch
### Версия: v1.2.3
### Приложение: com.windyx0.tgbypass

Комплексный системный модуль обхода блокировок Telegram и сетевого ускорения Linux через Root. Включает автономный фоновый сервис WebSocket-туннеля (127.0.0.1:1444), авто-инсталлятор модуля Vector (LSPosed) и мост-плагин для AyuGram.

---

## Возможности

1. **Сетевое ускорение ядра Linux (Network Turbo)**:
   - Активация алгоритма контроля перегрузок TCP BBR с дисциплиной очередей FQ.
   - Включение TCP Fast Open (TFO) для клиента и сервера (устранение задержки первого RTT при рукопожатии).
   - Отключение сброса окна при простое (tcp_slow_start_after_idle = 0) для мгновенной отправки сообщений.
   - Расширение сетевых буферов ядра до 16 МБ для быстрой загрузки потокового видео и медиафайлов.
   - Приоритизация трафика через QoS (DSCP AF41 / Low Delay).
   - Обход трекинга conntrack (NOTRACK) на интерфейсе loopback.
   - Автоматическое обнаружение MTU (Path MTU Probing).

2. **Автоматический запуск (Autostart)**:
   - Служба автоматически запускает туннель и применяет оптимизации ядра при загрузке системы (service.sh).
   - Управление автозапуском через CLI команду (`tg-ws-proxy autostart on|off`).

3. **Интеграция с Vector (LSPosed)**:
   - Автоматическая установка и активация модуля com.windyx0.tgbypass.
   - Настройка области действия (Scope) для официального Telegram, Telegram X, exteraGram, Plus Messenger и Nekogram.
   - Автоматическое исключение AyuGram из области Vector для предотвращения конфликтов ART.

4. **Интеграция с AyuGram**:
   - Автоматическая установка и активация Python-плагина tg_ws_vector_bridge.py в директорию AyuGram.
   - Двусторонняя синхронизация выбранного бэкенда в реальном времени.
   - Проксирование всего трафика, включая голосовые и видеозвонки (VoIP).

5. **Кнопка действия Action (KernelSU / APatch)**:
   - Быстрый запуск, проверка статуса и открытие Telegram в один клик из менеджера модулей.

## Установка

1. Загрузите архив модуля `TgBypass-Module-v1.2.3.zip`.
2. Откройте менеджер Magisk, KernelSU или APatch.
3. Перейдите в раздел "Модули" -> "Установить из хранилища".
4. Выберите архив и подтвердите установку.
5. Перезагрузите устройство.

---

## Управление через консоль (Root CLI)

В любом эмуляторе терминала (Termux / ADB Shell / su) доступна утилита `tg-ws-proxy`:

```bash
su
tg-ws-proxy status               # Статус прокси, слушающего порта и BBR
tg-ws-proxy start                # Запуск службы
tg-ws-proxy stop                 # Остановка службы
tg-ws-proxy restart              # Перезапуск службы
tg-ws-proxy autostart on|off     # Включение / выключение автозапуска
tg-ws-proxy apply-tg auto        # Найти Telegram и применить конфигурацию
tg-ws-proxy apply-tg all         # Применить конфигурацию во все клиенты
tg-ws-proxy set-target <пакет>   # Задать целевой клиент по умолчанию
tg-ws-proxy tune-net             # Применить оптимизации сетевого стека
```
